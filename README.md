# Smart Console-Based Task Manager

A modular, console-based task management system developed in C++ during my internship at **Shree Web Techno (May 2025 – July 2025)**.

This application enables users to efficiently manage daily tasks with persistent storage, user authentication, and CSV export functionality — all implemented using core Data Structures and File Handling concepts.

---

## Features

- User Registration & Login System  
- Add, Edit, Delete Tasks (Full CRUD Operations)  
- Task Searching & Filtering  
- Persistent Data Storage using File Handling  
- CSV Export Functionality  
- Linked List-Based Dynamic Data Management  
- Improved Input Validation & Error Handling  
- Clean Console UI with Structured Menu System  

---

## System Architecture

The system is designed using modular C++ programming principles:

- **Linked List Data Structure** for dynamic task storage  
- **File Handling** for persistent user & task data  
- **Menu-Driven Console Interface** for user interaction  
- **Separate Functional Modules** for improved maintainability  

---

## Tech Stack

- **Language:** C++  
- **Concepts Used:**  
  - Data Structures (Linked List)  
  - File Handling

  - CSV File Export
